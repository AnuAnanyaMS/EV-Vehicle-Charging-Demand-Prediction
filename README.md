# EV Vehicle Charging Demand Prediction

A machine learning and data analytics project that analyzes historical electric vehicle (EV) registration data and forecasts future EV growth trends across regions.

## Overview

The increasing adoption of electric vehicles creates a need for better understanding and forecasting of future EV demand. This project analyzes historical EV registration data and applies machine learning techniques to generate future forecasts.

An interactive Streamlit web application was also developed to make the analysis accessible to users. The application allows users to explore historical EV data, select regions, generate forecasts, and compare trends.

## Problem Statement

As electric vehicle adoption continues to grow, government authorities, urban planners, utility providers, and other stakeholders need data-driven insights to understand future EV demand.

Without reliable forecasting and visualization tools, it can be difficult to identify growth patterns and support future EV infrastructure planning.
